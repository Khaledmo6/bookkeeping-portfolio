# QuickBooks Online Bookkeeping Portfolio

This is a public-ready static portfolio page for a fictional sample bookkeeping project.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`.
3. Open Settings → Pages.
4. Choose Deploy from a branch.
5. Select the main branch and `/root`.
6. Save and wait for the Pages URL to become available.

The page clearly labels the project as a sample/practice project.
